## Overview

This repository contains beginner-friendly HTML snippets and mini examples that showcase core web development concepts such as:

- semantic page structure
- forms and inputs
- navigation and layout
- cards, tables, and media
- responsive design basics
- reusable markup patterns

Whether you're learning HTML for the first time or want quick reference examples, this repo is meant to be simple, readable, and easy to explore.

## Why this repo?

- Minimal and beginner-friendly
- Easy to copy into a browser or code editor
- Great for learning by example
- Focused on clean, standards-based HTML

## Getting Started

1. Open any example file in your browser.
2. Edit the markup in a local code editor.
3. Refresh the page to see your changes.

```bash
# Clone the repository
git clone https://github.com/huynhw19/HTML-examples.git

# Open the folder
cd HTML-examples
```

## Suggested Learning Path

- Start with basic document structure
- Explore headings, paragraphs, lists, and links
- Practice forms, labels, and input controls
- Build a simple layout using divs, sections, and containers
- Add semantic tags like header, main, nav, and footer
